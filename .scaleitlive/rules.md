# ScaleItLive Project Rules

- Inspect the existing implementation before editing.
- Preserve existing project data, content, assets, routes and components.
- Never invent replacement content when usable project content already exists.
- Build mobile-first; do not simply squeeze desktop layouts onto mobile.
- Do not redesign approved UI unless explicitly requested.
- Prefer existing dependencies and reusable components.
- Keep animations performant and respect reduced motion.
- Avoid unnecessary dependencies.
- Make targeted changes only.
- Do not run build/dev/tests unless explicitly requested.
